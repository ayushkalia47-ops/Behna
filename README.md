# Behna Bikinis — website

South Asian–inspired swimwear. Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · lucide-react.
No backend and no database: the catalog lives in one data file and the bag runs in the browser.

> **Status: preview store.** All imagery, the hero film, prices, product copy, the size chart and the policy
> pages are **placeholders**. The bag works, but **checkout is not connected**, so no orders or payments can be taken.

---

## Run it locally

You need Node.js 20.9 or newer. This machine has Node 22 installed at `~/.local/node`, so put it on your PATH first:

```bash
export PATH="$HOME/.local/node/bin:$PATH"
```

```bash
npm install
```

```bash
npm run dev
```

Open http://localhost:3000. For a production build:

```bash
npm run build && npm run start
```

To make Node permanent, add the `export PATH=…` line to `~/.zshrc` (or install Node from nodejs.org).

When the real photography is in, set `showPlaceholderNotes: false` in `src/config/site.ts` to hide the
"placeholder film" caption on the hero.

### Hero film tips
- Muted, 8–20 seconds, loops cleanly, H.264 MP4, ideally under 8 MB each. A separate vertical cut for phones
  makes a big difference; phones only ever download the mobile file.
- Export the first frame as the poster JPG. It shows instantly, while the video loads, and if video can't play.
- People who turn on "reduce motion" see the poster, and the play button starts the film.

### Product photo tips
- 4:5 portrait, about 1600×2000, JPG or WebP. Next.js resizes and serves modern formats automatically.
- Tag each image with the `color` id it shows. The product page puts the selected colorway's images first.
- The 2nd image of a product is the one that appears when a shopper hovers the card.
- Example after adding photos:

  ```ts
  images: [
    { src: "/assets/products/padma/padma-emerald-front.jpg", alt: "Model wearing Padma in Emerald by the pool", color: "emerald", width: 1600, height: 2000 },
    { src: "/assets/products/padma/padma-emerald-detail.jpg", alt: "Close-up of Padma's lotus print and gold ties", color: "emerald", width: 1600, height: 2000 },
  ],
  ```

### Placeholder artwork
Every placeholder image is labeled `PLACEHOLDER` and names the shot it stands in for (a shot list for your
photographer). They're generated by `scripts/generate-placeholders.mjs` (`npm run placeholders`). The
placeholder film is abstract motion rendered by `scripts/placeholder-video.swift`. Neither is product
photography; delete both scripts once you have real assets.

## Before you can take real orders

| Area | Status now | Needed |
| --- | --- | --- |
| Catalog and inventory | Static sample data | Shopify products + variants (color × size), inventory |
| Bag | Works, stored in the visitor's browser | Shopify Cart API, so the cart survives across devices |
| Checkout and payments | **Not connected** (button disabled) | Shopify Checkout, reached via `cart.checkoutUrl` |
| Shipping and taxes | Not calculated | Shopify shipping zones and tax settings |
| Order management | None | Shopify admin |
| Waitlist | Validates, but **stores nothing** | An email provider (below) |
| Policies | Drafts | Final shipping, returns, privacy and terms text |
| Product facts | Sample copy | Real fabric composition, care, fit, prices |

## Connecting Shopify (recommended path)

1. **Create the store** (any plan with Online Store or Starter). Add the 8 products with handles that match
   (`padma`, `gulabi`, …), options **Color** and **Size**, prices, inventory and images.
2. **Create a Storefront API token:** Settings → Apps and sales channels → Develop apps → create an app →
   enable Storefront API scopes (`unauthenticated_read_product_listings`, `unauthenticated_write_checkouts`,
   `unauthenticated_read_checkouts`). Put the domain and token in `.env.local` (see `.env.example`).
3. **Swap the data layer:** in `src/lib/commerce.ts`, replace `getProducts` / `getProduct` /
   `getRelatedProducts` with Storefront GraphQL queries (`products`, `product(handle:)`,
   `productRecommendations`) and map the response onto the existing `Product` type. The pages stay unchanged.
4. **Swap the bag:** in `src/components/cart/CartProvider.tsx`, call `cartCreate` / `cartLinesAdd` /
   `cartLinesUpdate` / `cartLinesRemove`, store the cart id in a cookie, and use the variant id as the
   line `id`. In `BagContents.tsx`, turn the disabled button into a link to `cart.checkoutUrl`. Shopify
   then handles payment, shipping, tax and order emails, so card details never touch this site.
5. **Availability:** map Shopify's `availableForSale` / inventory onto `status`, and add `offers` to the
   product JSON-LD in `src/app/products/[handle]/page.tsx`.

(Alternative: Shopify's Hydrogen framework. This codebase is designed for the lighter "Next.js + Storefront
API" route, which keeps the design fully under your control.)

## Connecting the waitlist

Set `NEXT_PUBLIC_WAITLIST_ENDPOINT` in `.env.local` to any URL that accepts `POST {"email": "…"}` as JSON.
- **Klaviyo:** add a small route (e.g. `src/app/api/waitlist/route.ts`) that calls Klaviyo's "Create Client
  Subscription" API with your public key + list id, and point the variable at `/api/waitlist`.
- **Shopify Email:** once the store is live, create customers with `acceptsMarketing: true`
  (Storefront `customerCreate`) from that same route, then email them from Shopify.
- **No code:** Formspree / Zapier / Make webhooks also work.

Until it's set, the form validates the address and then tells the visitor plainly that signups aren't open yet.

## Hosting and domain

The simplest host is **Vercel** (made by the Next.js team, free tier):
1. Push this folder to a GitHub repo, then "Import project" on vercel.com. It detects Next.js automatically.
2. Add your env vars (`NEXT_PUBLIC_SITE_URL=https://behnabikinis.com`, Shopify keys, waitlist endpoint).
3. Under Domains, add `behnabikinis.com` and follow the DNS instructions at your registrar (an A record
   for the apex, a CNAME for `www`).
4. If Shopify uses a subdomain for checkout (e.g. `shop.behnabikinis.com`), point it to Shopify in your DNS
   and set it as the checkout domain in Shopify → Settings → Domains.
